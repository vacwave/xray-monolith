- Temporary instrumentation: exact-string edits, revert with `git checkout -- file` (a whole-file rewrite turned CRLF into LF). After restoring a file MSBuild may skip the recompile (older mtime): touch it, then `grep -c -a "<marker>" exe` must be 0.

- game_launch waits 120 s for the MCP port regardless of `timeout`: an instrumented GAMMA startup must stay under that. - game_perf blocks the tool call: schedule the action inside the window with lua CreateTimeEvent(...,1,...) or game_input wait=false. `performancetest` starts with the tutorial_sleep CUISequencer active (game_state mode "tutorial").
- Profile artefacts to ignore: `prof_report` / `build_report` (~18 ms each), `components` / `level_path` (game_move_to planning), the first 3 s after a load (collectgarbage in game_loaded 113-123 ms, destroy queue, HUD texture apply_load). ## Code facts and gotchas (from the fixes)
- A second luabind Lua state exists (renderer `LSVM`, ResourceManager_Scripting.cpp); per-state caches in luabind must bind to the game state explicitly (F5 `pcall_cache_reset` from CScriptStorage; ST4 opts in with luaJIT_gc_udhint from CScriptStorage::reinit, released in lj_gc_freeall).
- `vs_to_layout` is keyed by the signature blob; `_DeleteVS` erases that signature's layouts from every declaration (R7 resets its memo there).
- dx10ConstantBuffer keeps a CPU copy; `AccessDirect` always marks dirty and callers must write before the next Render (grass `c_ExData` relies on the `array` re-map in the same $Globals buffer). New writers of `m_a*Constants` must rebuild `m_aBoundCBuffers`.
- textures_ps/vs/gs/hs/ds/cs are written only by CBackend::Invalidate and set_Textures (keep textures_*_end correct). light::m_xform inputs are snapshotted in m_xform_in (new xform_calc inputs go there).
- New writers of `xrServer::entities` must go through `entity_Insert` or clear `m_entity_by_id`.
- `smart_cast<T*>(CObject*)` falls back to RTTI unless smart_cast.h has a specialization; CObject declares cast_inventory_item / cast_weapon / cast_missile etc.
- LTCG (/GL, /Ob3, static libs) does not inline medium loop functions across libraries: check with dumpbin /disasm. `IC` = inline, `ICF` = __forceinline.
- lua_pushstring / lua_newuserdata run lj_gc_check: removing one from a hot path moves the GC step, it does not remove it. LJ_NOINLINE on lj_gc_separateudata / gc_clearweak / gc_mark_mmudata makes them visible in profiles. `<intrin.h>` clashes with lj_def.h BitScan prototypes in LuaJIT C files.
- VERIFY runs in DX11-AVX for xrGame (USE_VERIFY_IN_RELEASE) and logs through soft_fail: changing a VERIFY changes the log.
- CInifile section names are not always lowercase (DLTX fallback parents keep case); section_exist matches exactly, r_section lowercases a copy.
- Loading frames return from on_idle before FrameMove / seqRender / the limiter; theora textures decode only when a draw binds them. g_bootComplete is FALSE from LoadBegin to destroy_loading_shaders.
- Level collision build (CDB::MODEL::build_tree, Opcode) runs as a concurrency-runtime task, ~1.2 s; CSpaceRestrictor::inside rejects first against m_selfbounds.
- `CUISequencer::Start` keeps game_tutorials.xml in a function static (once per process; reloads while !g_bootComplete). ST5 preloads it on the first in-level frame (that frame still costs ~1.4 s GAMMA).
- GAMMA has ~730 `actor_on_update` listeners (564 = one closure per online anomaly, drx_da_main.script:2733): register bursts on walking. No GAMMA mod overrides axr_main.script (the db0 copy is live). `callback_reorder` still costs ~3-5 ms per registration burst (AX1).
- GAMMA hide_grip_gl.script calls set_bone_visible(hud=true) for every weapon that comes online → builds a HUD item each time (ST3 made that cheap). get_shaders(true) / get_default_shaders(true) (script_game_object.cpp ~1470/1496) build HUD data via HudItemData() for any CHudItem, also NPC-held. User idea "build HUD data only for the actor's weapons" tested 11-26: no difference, dropped.
- First weapon draw after a load still loads the HUD model on main (`CHudItem::HudItemData` → `attachable_hud_item::load` → model_Create); S2 prefetch rejected.
- After X4, TinyXML only sees DXML output: malformed raw XML that slaxml reads now loads (user-approved). DXML returns raw text for text\ files other than eng/rus and character_desc_general.xml, a cache when cached, raw on its own parse error. DXML round trip is NOT identical to raw input (attr values with spaces truncated, comments dropped). GAMMA ships its own patched dxml_core / slaxml in modpack_patches.
- U1 (UI texture reload per news burst) not reproduced 11-25: news bursts 0 hitches; PDA first open 54-57 ms once per session; no code change.
- Gamedata for tests: pack in the scratchpad (copy compressor\ + gamedata\, run xrCompress there), swap `C:\Anomaly\db\mods\00_modded_exes_gamedata.db0` with a backup, restore after.
