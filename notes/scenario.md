# Scenario tools (game_spawnable / game_spawn / game_give / game_actor / game_kill / game_release / game_weather / game_emission)
- Supervisor-only (block `scenario tools` before `main()` in `mcp/anomaly_mcp.py`): `SC_*` Lua chunks via lua.exec, args as a Lua literal (`sc_lit`), each chunk returns one JSON string (tiny encoder `J` in `SC_PRE`); `{error}` -> ValueError with the extra keys appended. No engine/gamedata changes.
- `sc_exec` refuses while hung or `engine.heartbeat` says loading; chunks needing a level check `level.present() and db.actor and alife()` -> "not in game" (main menu). Catalog works at the main menu.
- Catalog = Anomaly's debug spawner lists: `ui_debug_main.id_to_spawn_table` + `get_spawn_table(name)` (~2160 sections incl. mods; blacklist/`_base`/story NPCs/weapon variants already filtered). Category key = list name lowercased, non-alnum -> `_` (`Items (Food)` -> `items_food`). Cached per (instance, pid). Only catalog sections are spawnable (decided: safe against class-less / engine-only sections); phantoms rejected.
- Spawn kinds: `squads_*` -> squad, `npc_mutant` monster, `npc_stalker` stalker, `vehicles`, `anomaly`, `physic_misc` physic, everything else item.
- Squads exactly as the debug spawner / `create_squad_at_named_location`: `alife_create(sec,pos,lv,gv)`, `squad:create_npc(nil,pos,lv,gv)`, per member `SIMBOARD:setup_squad_and_group` + `squad_on_npc_creation` callback. No smart: sim assigns a target smart within seconds; they fight/move like natural squads.
- Relation: squads `set_squad_relation(rel)` (offline members get `force_set_goodwill(+-1000, actor)` on the server object -> persists in saves); single stalkers `se:force_set_goodwill`. Monster squads ignore it. Verified enemy/friend survive save+load.
- Items in the world: `alife_create_item(sec, {pos+0.3 up, lv, gv})`; anomalies get the debug spawner's stpk shape (here radius 3 instead of its 10).
- Placement: position -> nearest AI node (own node, else rings up to 30 m); else `distance` along the camera yaw; a static ray (`ray_pick` rqtStatic from eye height) shortens items in front of a wall, creatures/squads try 8 directions and take the first free one (`turned_deg` note). gvid = actor's game vertex (as the debug spawner; no Lua cross table).
- Gotcha: `level.vertex_id(p)` is valid when any node is under p's x/z even if p.y is far below the ground; teleport (`TP_PLACE`) now lifts such a point onto the node (it dropped the actor through the world).
- Gotcha: `alife_release` returns false and does nothing for creatures without a squad (debug-spawned monsters/stalkers); `SC_RELEASE` then does `alife_record(se,false)` + `alife():release(se,true)`. Squad releases complete a frame later (polled up to 2 s).
- Kill: `obj:kill(obj)` (debug launcher) or `obj:kill(db.actor)` with by_actor; squad id -> online members; verified death bookkeeping (squad removed after its last member died) and corpses with loot. No NPC death event type in game_events.
- Give: `alife_create_item(sec, db.actor[, {ammo = rounds}])` (itms_manager splits rounds into full boxes); equip = `move_to_slot(obj, ini slot + 1)` (inventory event: slot fills a frame later, polled), weapons then `activate_slot`. Remove = `iterate_inventory` + `alife_release_id`.
- Actor stats: `change_health/power/...` only queue a delta for the next condition update (and god mode keeps it pending until `g_god off`); use absolute setters: `set_health_ex`, `.power`, `.radiation`, `.satiety`, `.psy_health`; `.bleeding = 1` heals all wounds. Lua's `actor.satiety` getter always returns 1 (CActorCondition::GetSatiety is non-const, not an override) -> before/after come from state.get.
- Weather: `level_weathers.get_weather_manager()`; cycles = `wm.presets` {cycle: {preset=true}} (clear, partly, cloudy, rain, storm, foggy); applied by setting `wm.cycle/preset`, clearing transition/pre_blowout/weather_fx, `reset_change_date(true)`, `select_weather(true)` -> holds a full period and survives saves. Other files (`$game_weathers$`) via `level.set_weather(name,true)` (replaced at the next game hour). Non-atmosfear levels (indoor) only note it.
- Time: forward only, `level.change_game_time(d,h,m)` + `wm:forced_weather_change()`. Gotcha: jumping past a scheduled surge shows "An emission has recently occurred" PDA messages (skipped surge).
- Emission: `surge_manager.start_surge()/stop_surge()` (= end_surge(true)), `psi_storm_manager.start_psi_storm()/stop_psi_storm()`; start can silently skip (level not in `level_weathers.valid_levels`, option `alife/event/emission_state`/`psi_storm_state` off, generators/hospital, `on_before_*` flags) -> note. Surge sets time factor 10 (back to 6 on stop); weather_fx true a few s after start; surge_time 222 s.
- Stress (Cordon, 30 fps cap, 10 squads ~35 NPCs + surge): worker Lua 1.4 -> 2.2-2.6 ms/frame, worker Lua entries 244 -> 396/frame, game thread 2.2 -> 4.4 ms, main busy 2.1 -> 3.0 ms, engine allocs 767 -> 1369/frame, Lua heap growth 68 -> 137 KB/frame; main-thread Lua unchanged (~0.35 ms; actor_on_update callbacks).
- Gotcha (fixed 2026-11-16): engine slot = ini `slot` + 1 (`inventory_item.cpp:122`); `SC_EQUIP` used the ini value, so `detector_simple` (ini 8) went into slot 8 = PDA_SLOT, `GetPDA()` C-casts it to CPda and the game crashed in `CUIHudStatesWnd::UpdateZones` (0xE06D7363). Verified after the fix: detector -> slot 9, wpn_ak74 -> slot 3, PDA stays in 8. Anything non-PDA in slot 8 crashes the HUD.
- Artefacts lying in the world are invisible and cannot be picked up (CanPickItem needs getVisible) unless a detector is active (slot 9 + `detector` action); then `use` while looking at it picks it up.
