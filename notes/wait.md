# game_wait (wait / sync primitive)
- Supervisor-only block `game_wait` before `main()` in `mcp/anomaly_mcp.py` (`wt_*`, `wait_run`); engine change: `lua.exec {"quiet":1}` skips run_logged (no `* [MCP] exec #N` marker lines, no line capture) so predicate polls do not spam the log.
- Decided: grammar = JSON (strings for shorthands, one main key per object, `all`/`any`/`not`, plain list = all); validated up front with errors listing the valid keys/kinds/event types. Bare strings: in_control, loaded, main_menu, hung, crash, or an event type/glob.
- Decided: no engine-side predicate method. Polled leaves share one pipelined batch (`wt_batch`: all requests sent at once, the engine answers them in one frame) after an `engine.heartbeat`; measured no fps difference (uncapped ~420-437 fps idle vs 426-434 during 1-leaf and 4-leaf waits, ±2% noise) at ~16 polls/s (poll_ms 50 + round trip).
- Push wake: `Instance.wake` (Condition) is notified by the reader after every log line / game event and on disconnect; the wait re-checks buffer seqs under the lock before sleeping, so no wake-up is lost. Gap fills do not notify (covered by the poll / 0.25 s fallback).
- Events: since = events.last_seq at call start (or `since`); first match latched; result `event_seq` = matched event's seq (else the newest seen) for chaining; verified two back-to-back task_given events via chained waits. Same for log (`log_since` / `log_seq`).
- in_control = heartbeat not loading + state mode not loading/main_menu + TP_PROBE (level, afterFirstUpdate, alive) via quiet lua.exec; `{"in_control": level}` pins the level (a new game is in control on fake_start first).
- Decided pause policy: sim_ms / game_clock while MCP-paused with no steps running -> ValueError at the first poll (use game_step or resume); a game_step running concurrently advances them. frames work while paused (frames keep rendering).
- Loads: heartbeat loading -> polled leaves value "loading", wait continues; batch timeout min(3 s, remaining). Crash/exit -> immediate `failed_on: crash|exit` with reason/stack/dump (crash event arrives before the process exits); Lua predicate errors (runtime or syntax, pcall'd: no Busy Hands box) -> `failed_on: lua_error`.
- game_clock: target HH:MM from stats.game_time_ms (ms since the calendar epoch; days = 86400000 ms); needed delta fixed at the first sample (next day if past); rebased if game time goes backwards (earlier save loaded).
- Timings: already-true condition ~20-30 ms (1 round trip at 30 fps cap); in_control during a level change returned 2.3 s before game_teleport (its 1 s probe loop + final steps); count of hostile dogs == 0 returned 30 ms after the last game_kill; sim_ms 4000 at sim_speed 4 -> 1.04 s wall; 50 waits -> game private bytes +2 MB (noise).
- `wt_path` selects list elements by index or by `id` field (`tasks.<task id>.stage`), so `{"state": "tasks.X.stage", "eq": 1}` works; task completion = `{"event": "task_completed", "where": {"id": X}}`; numeric `where` values compare with ==.
