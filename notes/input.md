# Input
- `CInput` xrEngine/xr_input.h:16 = DirectInput8 buffered; keyboard `KeyUpdate` Xr_input.cpp:190 → `cbStack.back()->IR_OnKeyboardPress/Release/Hold` :255-268; mouse `MouseUpdate` :434 → IR_OnMouseMove/Wheel :626.
- `CLevel::IR_OnKeyboardPress` Level_input.cpp:160 maps key → action via `get_binded_action`; action ids (kFWD…) in xrGame/xr_level_controller.cpp.
- Existing simulation: Lua `level.press_action/release_action/hold_action` level_script.cpp:1294-1310 (bound :3174) call `Level().IR_OnKeyboardPress(cmd)`. Mouse look needs a C++ `IR_OnMouseMove` call.
- MCP input (`xrEngine/mcp_input.{h,cpp}`, methods input.run/input.status/input.release_all): `mcp_input::on_frame()` is called at the end of `CInput::OnFrame` (seqFrame REG_PRIORITY_HIGH, after real Key/MouseUpdate); events go to `pInput->CurrentIR()` (= cbStack.back()) like real input, so level, main menu, dialogs, inventory, PDA and console all receive them.
- Injected state: public `CInput::mcpKBState[256]` / `mcpMouseState[8]` (logical buttons) OR-ed into `iGetAsyncKeyState` / `iGetAsyncBtnState`, so game code polling key state and `IR_OnDeactivate` see injected keys. Hold: keyboard every frame incl. the press frame, mouse from the frame after the press (as CInput); diks >= 256 (kCUSTOMn) get press/release only.
- Silent runs: DirectInput is DISCL_FOREGROUND, so `KeyUpdate` returns early (Acquire fails) and real input never reaches the game; with focus (-showwindow) real and injected input mix (both dispatch; a real release of an injected key sends a release).
- Mouse dik MOUSE_1..8 (0xED+100..107) is delivered as `IR_OnMousePress/Release/Hold(btn)`; wheel as `IR_OnMouseWheel(±120 per notch)`; raw moves summed per frame into one `IR_OnMouseMove`.
- Look in degrees bypasses mouse sensitivity: xrGame hook calls `g_actor->cam_Active()->Move(kRIGHT/kLEFT | kDOWN(=look up)/kUP, rad)` (Move with val 0 means default speed, so zero is skipped). Verified exact (90.000°), pitch clamps at ±85.94° (lim_pitch). Applies to the camera even when a dialog is open.
- look_at/look_dir: delta from `Device.vCameraDirection`/`vCameraPosition` at step start; `Fvector::getH()` grows to the LEFT (yaw_right = -(Ht-Hc)), getP + = up. Measured ±0.4°.
- Text: `{"text"}` → per char `VkKeyScanExW` + `MapVirtualKeyExW(VK_TO_VSC)` with `GetKeyboardLayout(0)` (same layout as `CInput::dik_to_text`), LSHIFT down/up around shifted chars; chars needing Ctrl/Alt fail. Verified in the console (`mcp_typed_Text_1`).
- Names (xrGame/mcp_input.cpp hooks): actions = `actions[]` bind names + aliases (fire aim zoom reload pda sprint walk menu strafe_left/right lean_left/right detector flashlight) → bound dik via `get_action_dik`; keys = `keyboards[]` names with or without the `k` prefix (ESCAPE, W, k1/1, mouse1) + aliases (ESC ENTER BACKSPACE CTRL SHIFT ALT PGUP PGDN CAPSLOCK TILDE LMB RMB MMB).
- Defaults (mcp/templates/user.ltx): accel = LSHIFT (walk), sprint_toggle = X, crouch LCONTROL, inventory TAB, active_jobs (PDA) CAPITAL, quit ESC. Measured on l01_escape: run 2.7 m/s (2 s from rest), sprint 5.6, crouch 1.2, walk 1.1.
- 3D PDA (g_3d_pda on): kACTIVE_JOBS → `CInventory::Action` activates PDA_SLOT (8); with the PDA only in the backpack nothing happens (that was the "PDA does not show" issue: game_teleport's kit left it in the ruck). In the slot, tapping `pda` draws it and the UI shows (verified by screenshot); tap again hides it.
- Weapon fire/zoom are ignored while the weapon is still drawing/pending (an RMB right after wpn_2 did nothing; later it worked).
- Gotcha (goal 19): `CUICursor` uses the Windows cursor (`GetCursorPos`) when the window is >= screen size (`m_b_use_win_cursor`), so in silent fullscreen-size runs raw `mouse` moves do not move the UI cursor (it vanished off-window); `SetUICursorPosition` calls `SetCursorPos` (moves the user's real cursor).
- Disconnect: `mcp::client_id()` (conn_id) is polled in on_frame; any change (client lost or new client) releases all held keys and cancels sequences (logs `* [MCP] input: client changed, releasing N key(s)`). Verified by killing the supervisor mid 30 s hold.
