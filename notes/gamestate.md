- Task from Lua: `local t = CGameTask(); t:set_id(id); t:set_title(s); db.actor:give_task(t, 0, false, 0)`; `db.actor:set_task_state(task.completed, id)` (task.fail / in_progress / completed).
- Kill the actor: `db.actor:kill(db.actor)` (CActor::Die gets the actor as killer).
- `state.get {"sections":"inventory,tasks,stats"|"all"}` (xrGame/mcp_state.cpp, `mcp_register_state()` in OnAppStart) -> one JSON snapshot; supervisor tool `game_state` (sections list). Engine cost ~0.12 ms default / 0.18 ms all; supervisor round trip = 1 frame; 600 calls, no private-bytes growth.

- Gotcha: Anomaly script modules keep their globals in the module table (`surge_manager.SurgeManager`), not `_G`.
- Mode order: loading (pApp->IsLoading, level without name, or level without actor yet) > main_menu / in_game_menu (MainMenu()->IsActive) > dead > dialog (CurrentGameUI()->TopInputReceiver) > tutorial (g_tutorial active) > paused > in_game; console open -> mode console + under_console.
- Death: actor GetfHealth() is -1 after death; Anomaly starts tutorial `game_over` (CUISequencer becomes pInput->CurrentIR()).
- Dialog kinds: CUIActorMenu (menu_mode), CUIPdaWnd (pda, also the 3D PDA), CUITalkWnd (talk, partner from OthersInvOwner), CUIMessageBoxEx, script windows (CUIDialogWndEx). Anomaly inventory, loot and trade are all the script window `UIInventory`; its Lua field `mode` (inventory/loot/trade/repair) -> script_mode, `npc_id` -> partner.
- Lua class name of a script window: dynamic_cast to `luabind::wrap_base`, `wrap_access::ref()` weak_ref (m_impl null check via raw pointer: private), push it, `is_class_object` -> `crep()->name()`; fields read with a pcall'd chunk. Main menu window = script class `main_menu`.
- yaw/pitch from Device.vCameraDirection: yaw = atan2(x, z) (0 = +z, +90 = +x, grows when turning right like game_input look), pitch = asin(y). Verified: look +90 -> yaw 90; then -45/+20 -> 45/20.
- Weapon spare_ammo = GetSuitableAmmoTotal - elapsed; with god mode / unlimited ammo GetSuitableAmmoTotal is a fake 999 -> `unlimited_ammo: true` instead.
- Crosshair target = HUD().GetPick().result (O, range): ground hits give distance only; relation via RELATION_REGISTRY().GetRelationType(target, actor).
- NPC talk from a script: `npc:enable_talk()` + `db.actor:run_talk_dialog(npc, false)` did not open the window for a sim stalker; `use` on Sidorovich (esc_m_trader, -244.3,-24.81,-133.86; stand at -245.9,-24.81,-133.9 and look at his body) works; key `1` = trade.
- Lua errors in lua_exec (e.g. `:alive()` on non-entities, wrong give_task args) trigger Anomaly's "Busy Hands" message box (CUIMessageBoxEx) shown over the game.
