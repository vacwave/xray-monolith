# World queries (game_objects / game_object)
- `world.objects` / `world.object` (xrGame/mcp_world.cpp, `mcp_register_world()` after `mcp_register_state()` in OnAppStart); supervisor tools `game_objects` / `game_object` (block `game_objects` after game_state). Read-only.
- Decided: all facts in C++, no Lua chunk (squad/smart come from the server entity `CSE_ALifeMonsterAbstract::m_group_id` / `m_smart_terrain_id` + `name_replace()`, matched Anomaly's squads). Rank is the number (rank names are script-owned, not included).
- Decided: engine params are int/string only (mcp_server has no float/bool getters; not touched): radius as string or int, position "x,y,z", kinds csv, flags 0/1; the supervisor converts.
- Online scan = `Level().Objects` (`o_count`/`o_get_by_iterator`), skipping getDestroy, `H_Parent()` (items in inventories/boxes) and the actor; distance filter first, then classify via smart_cast.
- Kinds: stalker (CEntityAlive + CInventoryOwner, incl. traders), monster, corpse (dead creature, `of`), weapon/ammo/artefact/item (CInventoryItem), campfire (CZoneCampfire, `lit`), anomaly (CCustomZone, `type` = engine class, `enabled`), level_changer (destination = CSE_ALifeLevelChanger::m_caLevelToChange), smart_terrain (CSpaceRestrictor with CLS_ID SMRTTRRN), restrictor, container (CInventoryBox), vehicle (CHolderCustom/CHelicopter), ladder (CClimableObject), cover (smart_cover::object), door (CPhysicObject whose visual/section contains "door"), physic, squad (offline only), other (hanging lamps, crows...). Default = all but restrictor and cover (noise: ~90 smart covers in rookie village).
- Anomaly anomalies: many `enabled: false` (dynamic anomalies toggled by scripts); `radius` = CObject::Radius (3 for most mines).
- Bearing/elevation: from Device.vCameraPosition to the object's Center(), minus camera yaw/pitch (same convention as game_input look). Verified: look by (bearing, elevation) -> 0/0 and game_state.target = that NPC.
- los: RayPick rqtBoth from the camera to Center(), ignoring actor and target, range len-0.2; anything (level geometry, other objects) blocks. Cap 64 rays per call (`rays` in the result). Verified true in the open, false through Garbage hangar metal wall (screenshot) and for Sidorovich in his bunker.
- Crosshair `target` in game_objects: HUD().GetPick() distance, point = defs.start + dir*range, object id/kind/section or static-geometry material (`GMLib` via `GetStaticTris()[element].material`).
- offline: `ai().alife().graph().level().objects()` entries with ID_Parent 0xffff and no client object. In Anomaly the whole current level is online, so it is mostly squads (server-only) and a few boxes/items.
- Outside a level: `{available:false, reason: no_level|loading|no_actor|bad_position}` (result, not an error); supervisor answers `loading` from engine.heartbeat without waiting.
- Cost (Garbage, ~1000 online objects): default 0.28 ms, summary r500 0.22 ms, r500 limit 100 0.78 ms, r500 los (30) 0.68 ms, r500 los limit 100 1.6 ms (max 2.0), offline r5000 limit 100 0.96 ms; game_object 0.07 ms; round trip ~30 ms (frame-bound at the 30 fps cap). JSON: 7 KB default, ~25 KB at limit 100.
- Safety verified: main menu, ~50 calls through new game + level change (loading/fake_start), 200 calls during NPC spawn/kill/release churn, 600 calls -> private bytes +2 MB.
- game_object on an offline entity of another level (e.g. a task target squad) reports distance/bearing as if it were on the current level and has no level field.
